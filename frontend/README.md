# Frontend

This folder contains the Vite frontend for the chat app.

## Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Add a `.env` file if you want to override the backend URL:
   ```env
   VITE_API_BASE_URL=http://localhost:3001
   ```
3. Start the frontend:
   ```bash
   npm run dev
   ```
